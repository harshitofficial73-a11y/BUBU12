BUGS THE RETEST CAUGHT AND FIXED

  Registration called the profile function with the wrong parameter names,
  so no one could register on mobile. Fixed, and a half-finished attempt
  (auth user created, profile not) now resumes instead of dead-ending on
  "User already registered".

  A posted requirement did not appear under My requirements until the next
  full reload. The list now refreshes itself.

  Districts with spaces (Fort Portal) produced an id the database does not
  use. The id now comes from the real districts table.

  The chat header told a BUYER "Wants to buy …" about their own request.
  Buyers now see "About …"; suppliers keep "Wants to buy …".

  Failed connections during register/post no longer pretend to succeed.

CAMERA

  Every photo point uses accept="image/*" capture="environment", the
  standard browser mechanism: "Take photo" opens the phone's camera app
  directly, no permission prompt, no app install. It requires HTTPS, which
  Netlify already provides. Nothing to configure.
